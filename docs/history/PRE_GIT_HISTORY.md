# Pre-Git Development History

Git history begins with the Convergence 08 source baseline. Earlier versions were produced as archived ZIP artifacts and must not be reconstructed as fake Git commits.

High-level lineage:

- v0.7.2-RC3: frozen Golden Parent / verification foundation.
- v0.8.x: capability-complete line; evidence, privacy, identity, Knowledge, operations, Windows/release engineering matured here.
- v0.8.10: mature business/Windows assembly line.
- v0.8.12-R2: capability-completeness and judgment-consistency reference.
- v1.0-alpha10: lean recruitment-operations rewrite; useful workflow ideas but reduced capability density.
- Convergence 01–07: progressive reunion of alpha workflow with 0.8.x capability semantics.
- Convergence 08: first Git source baseline; project portability, graphical source grounding and deeper release/system guards.

Archived release ZIPs, if published, should be stored as GitHub Release assets rather than inserted into normal Git history.
